# S7 Windows worktree, cwd, and process kill

Question: on Windows, do short-path `git worktree add` and `remove` work, does `psutil` report the process cwd, can a process tree be killed, and does `core.autocrlf=false` stick?

Installed: psutil 7.2.2. Throwaway repo under `D:\tf\<id>`.

- `git worktree add` and `git worktree remove --force` succeeded. The worktree path was 15 characters.
- `git config --local core.autocrlf false` read back as `false`.
- `psutil` killed a parent and its children. The parent was gone and so were the children.
- `psutil.Process.cwd()` on the uv `Scripts\python.exe` launcher is `C:\Users\ASUS\AppData\Local\Temp`. The real interpreter is a child (`uv\python\cpython-3.12-...\python.exe`) and its cwd is the worktree. The isolation check has to follow that child.

Result: PASS
