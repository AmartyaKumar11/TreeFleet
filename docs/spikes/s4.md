# S4 ADK RemoteA2aAgent

Question: can `RemoteA2aAgent` call the worker, send a `DataPart`, receive a `DataPart` artifact, and can two of those run in parallel?

Installed: google-adk 2.13.0. The orchestrator extra does not install `a2a-sdk` (`RemoteA2aAgent` lives in the `a2a` extra). An unconstrained install resolved `a2a-sdk` 1.2.3. The worker environment has `a2a-sdk` 0.3.26, so the spike pinned the orchestrator environment to 0.3.26 before the call.

CrewAI does not serve HTTP (S3), so the peer was an A2A SDK app on `127.0.0.1:9101`, the fallback shape from S3. The card declared `streaming=false`. Each client sent a genai blob wrapped as `<a2a_datapart_json>` plus a serialized `DataPart`. The server echoed `{"echo": n}` as a `DataPart` artifact. Two runners with session ids `s1` and `s2` completed together via `asyncio.gather`, and both echoes came back.

`RemoteA2aAgent` is marked experimental by ADK 2.13.0.

Result: PASS
