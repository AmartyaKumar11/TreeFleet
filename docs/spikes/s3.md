# S3 CrewAI A2AServerConfig

Question: does `A2AServerConfig` on a CrewAI agent serve an agent card and answer `message/send`? Does it stream? Does it return input-required?

Installed: crewai 1.15.30, a2a-sdk 0.3.26.

`A2AServerConfig` injects `to_agent_card(url)`. That call returns an `AgentCard` whose capabilities declare `streaming=True`. The agent has no serve or listen method, and crewai 1.15.30 does not start an HTTP server. `message/send`, streaming behavior, and `input-required` are not observable because nothing is listening.

Result: FALLBACK Serve through an A2A SDK app whose executor runs the crew
